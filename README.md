# Maxim.dev Portfolio

Современный сайт-портфолио начинающего frontend-разработчика. Проект можно использовать как страницу для резюме, HH и откликов на junior-позиции.

## Demo

https://maxim-portfolio-seven.vercel.app/

## Стек

- React
- TypeScript
- Vite
- Tailwind CSS
- Framer Motion
- Lucide React

## Секции

- Header с навигацией
- Hero section
- Обо мне
- Навыки
- Проекты
- Контакты
- Footer

## Проекты внутри портфолио

- Vibe Coding AI Landing: https://vibe-coding-ai-omega.vercel.app/
- AI Resume Builder: https://ai-resume-builder-eta-teal.vercel.app/
- AI Task Dashboard: https://ai-task-dashboard-woad.vercel.app/

## Запуск

```bash
npm install
npm run dev
```

## Сборка

```bash
npm run build
npm run preview
```

## Деплой на Vercel

Стандартные настройки Vite:

- Build command: `npm run build`
- Output directory: `dist`
- Install command: `npm install`

## Что можно улучшить дальше

- Добавить скачиваемое резюме в PDF.
- Добавить favicon и Open Graph image.

## Для публикации на GitHub

В репозиторий не должны попадать `node_modules`, `dist`, `.vercel`, `.env` и системные файлы. Это уже настроено в `.gitignore`.
